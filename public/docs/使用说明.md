## 一、登录与权限

### 1.1 登录方式
- 系统支持「密码登录」「验证码登录」「注册」「重置密码」「绑定微信」五种入口
  - 入口代码：[src/views/_builtin/login/index.vue](../src/views/_builtin/login/index.vue)
- 登录成功后，系统会同时写入：
  - `localStg.token` / `localStg.refreshToken`（本项目使用）
  - `localStorage.access_token` / `localStorage.refresh_token`（资产端兼容）
  - Cookie `access_token` / `token` / `refresh_token`（跨子系统免登）
- Cookie 域名通过环境变量控制：
  - 开发：`VITE_COOKIE_DOMAIN_DEV=.test.com`
  - 生产：`VITE_COOKIE_DOMAIN=.datastring.cc`
  - 配置：[.env](../.env)

### 1.2 角色与权限
路由层面通过 `meta.roles` 控制可见菜单，角色编号如下：

| 编号 | 角色 | 说明 |
|------|------|------|
| 1 | 超级管理员 | 全部模块，含操作日志 |
| 2 | 管理员 | 除操作日志外的所有模块 |
| 3 | 售后/运维 | 故障机、矿场、矿场详情 |
| 4 | 维修人员 | 工单、维修明细 |
| 5 | 其他授权角色 | 主要业务模块 |

> 角色映射见 [routes.ts](../src/router/elegant/routes.ts) 各路由 `meta.roles`。
> 每次路由切换前会调用 `/api/getUserInfo?group_id=<当前组>` 校验权限，失败会自动退出。
> 代码：[src/router/guard/route.ts](../src/router/guard/route.ts)、[src/store/modules/auth/index.ts](../src/store/modules/auth/index.ts)

### 1.3 组（Group）切换
- 顶部导航支持下拉切换业务组
- 切换后 `activeGroupId` 会写入本地存储，并触发权限重新校验
- 代码：[src/layouts/modules/global-header/index.vue](../src/layouts/modules/global-header/index.vue)

## 三、各模块详细说明

### 3.1 首页（Home）
- 路径：`/home`
- 文件：[src/views/home/index.vue](../src/views/home/index.vue)
- 主要内容：卡片数据、折线图、饼图、项目动态横幅
- 适用角色：1 / 2 / 5

### 3.2 维修报表（Repair Report）
- 路径：`/repairreport`
- 文件：[src/views/repairReport/index.vue](../src/views/repairReport/index.vue)
- 主要内容：场地信息、维修站信息、指标图标
- 适用角色：1 / 2 / 5

### 3.3 矿场日报（Mining Site）
- 路径：`/miningsite`
- 文件：[src/views/miningSite/index.vue](../src/views/miningSite/index.vue)
- 子路由：`/miningsite/:id/info`（矿场详情，[siteDetail/index.vue](../src/views/siteDetail/index.vue)）
- 顶部筛选条件：
  - 名称、售后专员、站点状态、绑定工单类型、板子绑定类型、所有场地（含已撤场）、日期
  - 代码：[SearchBar.vue](../src/views/miningSite/components/SearchBar.vue)
- 表格字段：场地名称、资产数、24h 故障数、在物流中、待上架、在修数、上架待修数、待修数、待修率、净故障数、预报废数、异常机器数、今日上架数、机器工单绑定、板子工单绑定、场地状态、售后专员、操作
- 操作：
  - 「编辑日报」：进入日报编辑（无管理权限时仅显示该按钮）
  - 「编辑」：修改场地信息
  - 「查看」：进入矿场详情
- 状态说明：
  - 场地状态 `active` → 活跃，`inactive` → 非活跃，`remove` → 撤场
  - 异常机器数：扫描缺失机器（正数缺失，负数扫多）
  - 今日上架数：昨天 8:00 至今天 8:00 的上架数

### 3.4 工单列表（Workflow）
- 路径：`/workflow`
- 文件：[src/views/workFlow/index.vue](../src/views/workFlow/index.vue)
- 子路由：`/workflowdetail/:id`（工单详情，[workFlowDetail/index.vue](../src/views/workFlowDetail/index.vue)）

- 状态：已完成 / 维修 / 未解决 / 待处理 / 处理中

### 3.5 故障机管理（Faults）

## 六、常见问题

### Q1：登录后没看到某模块菜单？
- 检查当前账号角色是否在路由 `meta.roles` 内
- 检查是否切换到了正确的「业务组」
- 联系超级管理员调整角色

### Q2：进入页面被自动退出登录？
- 路由守卫调用 `getUserInfo?group_id=X` 失败
- 可能原因：token 失效、当前组无权限、网络异常
- 重新登录后切换可用组

### Q3：Excel 导入失败？
- 确认下载的是最新模板（`repair-detail-2026.xlsm`）
- 确认文件未损坏、未被密码保护
- 查看请求返回的错误信息
- 联系后端确认导入接口路径

### Q4：跨系统免登不生效？
- 确认两个系统部署在同一主域下（如 `.datastring.cc`）
- 浏览器 Application → Cookies 检查 `access_token` 是否存在
- 域名配置：[.env](../.env) 中的 `VITE_COOKIE_DOMAIN`

### Q5：表格列显示不下？
- 使用表头操作组件：[table-header-operation.vue](../src/components/advanced/table-header-operation.vue)
- 使用列设置：[table-column-setting.vue](../src/components/advanced/table-column-setting.vue)

## 七、开发与扩展指引

### 7.1 新增页面
1. 在 `src/views/<模块名>/index.vue` 创建组件
2. `elegant-router` 会自动生成路由
3. 在 [routes.ts](../src/router/elegant/routes.ts) 补充 `meta.roles` / `icon` / `order`
4. 在 [zh-cn.ts](../src/locales/langs/zh-cn.ts) / [en-us.ts](../src/locales/langs/en-us.ts) 补充 `route.<name>`
5. 在 [app.d.ts](../src/typings/app.d.ts) 补充类型声明

### 7.2 新增 API
1. 在 [src/service/api/](../src/service/api/) 对应文件新增方法
2. 在 [api.d.ts](../src/typings/api.d.ts) 声明请求/响应类型
3. 业务页面通过 `useRequest` / 直接调用

### 7.3 类型检查
```bash
npm run typecheck
```

### 7.4 启动开发环境
```bash
npm run dev
```
- 开发域名：`cc.test.com`（[vite.config.ts](../vite.config.ts)）
- 需要在本机 `hosts` 中将 `cc.test.com` 指向 `127.0.0.1`
