## 一、系统简介

维修管理系统是面向矿机维修业务的一体化管理平台，覆盖「矿场 → 工单 → 故障机 → 维修 → 报废」全流程。

主要使用角色：
- 超级管理员 / 管理员：全部模块
- 售后/运维：矿场、故障机
- 维修人员：工单、维修明细
- 只读用户：查看主要业务数据

## 二、登录与退出

### 2.1 登录

![登录页](screenshots/01-login.png)

**操作步骤：**
1. 浏览器打开系统地址（开发环境：`http://cc.test.com`）
2. 输入用户名、密码
3. 点击「登录」按钮

**支持的登录方式：**
- 密码登录（默认）
- 验证码登录
- 忘记密码 → 重置密码
- 注册账号

**跨系统免登：**
如果已经在同主域下的其他系统（如资产系统）登录过，打开本系统会自动登录，无需再次输入。

### 2.2 切换业务组

登录后可在顶部切换业务组，切换后菜单和数据会按当前组过滤。

![组切换](screenshots/02-group-switch.png)

### 2.3 退出登录

点击右上角头像 → 退出登录。

> 退出后会同时清除本系统和其他关联系统的登录态（统一退出）。

| 字段 | 含义 |
|------|------|

## 七、工单列表

![工单列表](screenshots/07-workflow.png)

### 7.1 功能概述
- 工单流转全生命周期管理
- 支持单个/批量派单、退回、修改

### 7.2 操作步骤

#### 7.2.1 派单
1. 在列表勾选要派单的工单
2. 点击「批量派单」按钮
3. 在弹窗中选择：
   - 维修方式（整机 / 算力板）
   - 就近维修站
   - 故障机数量
   - 备注
4. 点击「确认派单」

#### 7.2.2 退回工单
1. 点击工单行的「退回」按钮
2. 在确认弹窗中点击「确认」
3. 工单状态变为「用户退回」

#### 7.2.3 修改工单
1. 点击「修改」按钮
2. 在弹窗中修改：维修方式、维修站、维修费用、物流费用、付款状态等
3. 点击「保存」

### 7.3 工单状态说明

| 状态 | 含义 |
|------|------|
| 待处理 | 新建未派单 |
| 处理中 | 已派单待维修 |
| 维修 | 维修中 |
| 已完成 | 维修完成 |
| 未解决 | 维修未通过 |

### 7.4 付款状态

- 未付款 / 已付款

### 7.5 工单详情
- 路径：`/workflowdetail/:id`
- 包含：工单基本信息、故障机列表、操作日志

## 十四、通用操作指南

### 14.1 表格分页

![分页](screenshots/14-pagination.png)

- 默认每页 20 条
- 可切换：10 / 20 / 50 / 100
- 左下角显示总条数

### 14.2 表格排序
- 列标题带上下箭头图标 → 点击排序
- 支持排序的字段：资产数、故障数、维修数、费用等

### 14.3 表格列设置
- 表格右上角「列设置」图标
- 可显示/隐藏列、调整顺序

### 14.4 高级搜索
- 大部分列表页都有顶部搜索栏
- 输入条件后点击「查询」或回车
- 点击「重置」清空所有条件

### 14.5 Excel 导入通用流程

![Excel 导入](screenshots/15-excel-import.png)

**统一流程：**
1. 点击「导入」按钮
2. 在弹窗中点击「下载模板」
3. 按模板格式填写数据（请勿修改表头）
4. 选择填好的文件
5. 点击「确认导入」
6. 等待上传完成，查看结果提示

**注意事项：**
- 必须使用系统提供的最新模板
- 不要修改模板表头
- 文件不要加密、不要损坏
- 单次导入数据量建议不超过 5000 条

### 14.6 多页签管理

| 操作 | 方式 |
|------|------|
| 关闭当前 | 右键 → 关闭 |
| 关闭其他 | 右键 → 关闭其他 |
| 全部关闭 | 右键 → 关闭所有 |
| 刷新 | 右键 → 刷新 |
| 固定 | 右键 → 固定 |

### 14.7 主题与语言

- **主题**：右上角主题按钮，可切换暗黑模式、主题色、布局模式
- **语言**：右上角语言切换，支持中文 / English

## 十六、常见问题

### Q1：登录后看不到某模块菜单？
- 检查当前账号角色是否在权限对照表内
- 检查是否切换到了正确的业务组
- 联系超级管理员调整角色

### Q2：进入页面被自动退出登录？
- 可能原因：登录态过期、当前组无权限、网络异常
- 解决：重新登录 → 切换可用业务组 → 重试

### Q3：Excel 导入失败？
- 确认使用的是最新模板（不要拿旧模板）
- 确认文件未加密、未损坏
- 检查必填字段是否完整
- 查看错误提示详情，按提示修改后重传

### Q4：跨系统免登不生效？
- 确认两个系统在同主域下（如 `.datastring.cc`）
- 浏览器 Application → Cookies 检查 `access_token` 是否存在
- 清浏览器 Cookie 后重新登录一次

### Q5：表格列太多看不下？
- 使用表格右上角「列设置」隐藏不常用列
- 拖动列宽调整显示
- 横向滚动查看完整数据

### Q6：搜索条件不生效？
- 点击「查询」按钮触发搜索
- 部分页面支持回车搜索
- 点击「重置」后重新输入条件

### Q7：批量操作没反应？
- 检查是否勾选了记录（列表左侧复选框）
- 检查所选记录是否符合批量操作条件（如状态必须一致）
- 联系管理员确认账号是否有批量操作权限

### Q8：导出数据为空？
- 检查当前筛选条件是否匹配到数据
- 取消部分筛选条件后重试
- 联系后端确认导出接口权限
